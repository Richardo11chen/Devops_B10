# e11e12-1 接口契约

|接口|请求/响应|状态码|
|---|---|---|
|POST /v1/jobs|idempotency_key、input(mode/repo/base/target/candidate/subdir 等)；返回job_id/status|202，错误输入400，幂等冲突409|
|GET /v1/jobs/{job_id}|任务状态、trace_id、error|200，不存在404|
|GET /v1/jobs/{job_id}/artifacts|阶段清单与artifact URI/SHA256|200，结果未生成409|
|GET /v1/jobs/{job_id}/files/{相对路径}|产物文件与X-Content-SHA256|200，不存在或越界404|

任务状态 QUEUED、RUNNING、SUCCEEDED、FAILED、TIMED_OUT。输出 envelope 的 schema_version、job_id、trace_id、kind、commit、status、data、artifacts 为消费者依据。

`artifact://job编号/相对路径` 由该任务文件接口解析。MD 消费需核对目标 commit 和内容哈希。基线与目标提交不同是正常的，必须记录两者。

## 本项目对契约的增补

**请求字段 `subdir`（可选）**：项目位于仓库子目录时，声明该相对路径。

- 取值：克隆内部相对路径，如 `e3/fixtures/mdfixer`。
- 校验：解析后必须仍在克隆目录内且为已存在目录，否则 `UNSUPPORTED_PROJECT`。
- 缺省：不提供时项目即仓库根，与原实现一致。

**项目描述文件 `.lab-project.json`（可选）**：位于项目目录，声明该项目的目标映射与验证参数。

| 字段 | 含义 | 缺省 |
|---|---|---|
| `targets[].object` / `.source` | 目标文件与源文件 | `main.o/main.c`、`helper.o/helper.c` |
| `program` | 运行程序名 | `app` |
| `build_target` | 构建目标（`make X`） | `app` |
| `allowed_flags` | 接受的 `CFLAGS` 白名单 | `-O0`、`-O1`、`-O0 -DMODE=1` |
| `header` | 用于头文件变化检查的文件 | `config.h` |
| `expected_output` | 构建后程序应输出的内容 | `1` |
| `header_edit.from` / `.to` | 头文件内容替换规则 | `#define VALUE 1` → `#define VALUE 2` |
| `header_output` | 替换后程序应输出的内容 | `2` |

缺少该文件时全部取缺省值，行为与原 E8–E10 一致。未知 flags 不在白名单内会抛 `UNSUPPORTED_FLAGS`，不静默接受。

真实项目适配时将仓库和候选准备到 API 服务器 `data/` 下。服务仅开放到本地，A/B 通过 SSH 转发访问。
